# Space Shooter

A 2D space shooter game developed using Unity and C#.

## About the Project

Space Shooter is a 2D shooting game developed with Unity. 
The player controls a spaceship, shoots enemies, and tries to achieve a higher score.

This project was created as a game development project to practice Unity and C# programming concepts.

## Features

- Player spaceship movement
- Shooting system
- Enemy interactions
- Collision detection
- Score system
- Game over system
- 2D gameplay

## Technologies

- Unity
- C#
- Unity 2D

## Gameplay

The player controls a spaceship and uses the shooting system to destroy enemies and increase the score.

## How to Run

1. Clone or download this repository.
2. Open the project using Unity Hub.
3. Open the project in Unity.
4. Open the main game scene.
5. Press the Play button to run the game.

## Project Purpose

This project was developed to practice game development using Unity and C#, including player control, shooting mechanics, collision detection, and basic game logic.
